# 手机卡片封面加宽（2026-10-22）

## 原因
- 680px 以下原为 112×173，但后面的 410px 以下规则又将实际卡片封面改为 92×184，宽高比 1:2。该小屏覆盖仍在生效，导致手机封面呈窄长条。
- 此处是媒体网格卡片的 .anime-poster。列表视图使用独立 .anime-list-row，音乐列表另有方形封面组件。

## 修改
- 手机卡片只在 680px 断点设置一套共享尺寸变量：封面高度 200px，宽度按 2/3 计算为 133.333px；卡片高度 202px，包含上下各 1px 边框，右侧内容高度 200px。
- 删除 410px 断点的卡片、封面和内容区域尺寸覆盖，保留该断点的其他排版规则。
- 封面比截图中的 92px 宽增加约 45%。封面缩放位置和用户自定义裁切参数继续由原组件处理。

## 验证
- 源码级响应式尺寸检查覆盖 320、360、393、410、411、480、680px，均得到 133.333×200 封面、202px 卡片及 200px 内容区；681、900、1024px 对应尺寸与修改前一致。
- 上述检查为规则与尺寸计算，不是手机浏览器截图测试。现有浏览器没有移动视口调整能力，不虚报手机实机验收。
- 发布前等待 Actions 类型检查、lint、构建和全部现有测试通过；发布后核对实际加载样式。
