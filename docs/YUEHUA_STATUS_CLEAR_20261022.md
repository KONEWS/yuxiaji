# 状态筛选取消选择动画（2026-10-22）

## 复现和修复
- 线上复现：选中“进行中”，再次点击取消后，status-tabs 没有 active 按钮，但 --slide-x/y/width/height 同时变为 0，opacity 变为 0。正在进行的位移和尺寸过渡会把滑块缩向容器原点，出现飞出效果。
- 同时按钮 :hover 背景仍为 rgb(241,244,245)，触摸浏览器可能将其保留为粘滞悬停，导致取消后仍像被选中。
- 无有效选中项时保留最后的几何位置，仅让高亮在原位淡出。重新选中或隐藏导航重新出现时，先在新按钮处设置位置，再启用后续位移过渡。
- 未选中的状态按钮保持透明，避免残留悬停胶囊；键盘焦点样式仍保留。
